# Listo

A simple to-do list app that runs in the browser and installs to a phone's home screen.

- Several lists, colors, stars, optional notes on each item, drag to reorder
- Search, sort, Trash, backup and restore, Markdown export
- Works offline. All lists are stored on the device only; nothing is sent anywhere.

Files: `index.html` is the whole app. `manifest.webmanifest`, `sw.js` and the icons make it installable and available offline.
